### What the owner must do for the account-only steps

1. JLCDFM: sign in at https://jlcdfm.com (Sign In -> passport.jlcpcb.com, a JLCPCB account). Upload `TB1_jlc-altium26.zip` and `TB1_outjob.zip` from this folder, press DFM check, export the PDF (toolbar PDF icon), then run `python scripts/dfm.py ingest <project> <pdf>` and fill the JLCDFM column below with observed levels.
2. Assembly: same account; on https://jlcpcb.com/quote upload the zip, switch PCB Assembly on, NEXT, upload `jlc-testboard_BOM_jlc.csv` and `jlc-testboard_cpl.csv`, read the matching page; stop before Save to Cart.
3. A logged-in browser profile can be reused: close Edge and run `python scripts/jlc_live.py --profile "%LOCALAPPDATA%\Microsoft\Edge\User Data"`. The script then reports login=true; the logged-in upload/analysis capture itself is not automated yet.
