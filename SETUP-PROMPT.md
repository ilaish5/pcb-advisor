# Set everything up with an AI agent

Open a terminal in any folder, start a coding agent (`claude` or `agy`), and paste this one line:

```text
Install pcb-advisor from https://github.com/ilaish5/pcb-advisor following INSTALL-AGENT.md
```

The steps the agent follows are in [INSTALL-AGENT.md](INSTALL-AGENT.md). No agent yet? Use the one-command install
in the [README](README.md#install-about-5-minutes); it also installs Claude Code for you.
