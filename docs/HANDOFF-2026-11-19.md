This is for whoever continues the work (Antigravity / AGY). The project is a B.Sc. final project. The goal is zero technical errors and effortless use for the student.

## Ground rules (do not break)
- **Commits and pushes:** commit and push to `main` only after the full test suite passes and an independent code review is done. The push commands are `git push origin phase0-correctness` and `git push origin phase0-correctness:main`.
- **Tests:**
  - Full suite: `.venv/Scripts/python -m pytest -q -p no:cacheprovider`. The summary line is suppressed: rc=0 means everything passed, and failures show as FAILED/ERROR lines.
  - Lint: `.venv/Scripts/python -m ruff check scripts tests`.
  - The suite takes more than 10 minutes and uses a lot of RAM, since the machine has 8 GB. Run it only when nothing else heavy is running. If it is killed for low memory, do not restart it automatically.
- **What goes to GitHub:** only generic code and general sources. Part datasheets and all project data stay in `projects/<name>/` and never go to GitHub.
- **Altium:**
  - Never restart the server on port 8931.
  - Never call `WorkspaceManager:CloseObject` from a script.
  - Do not run `X2.EXE -REditScript:Stop`, because it opened a second Altium in the past.
  - Do not write diagnostic DelphiScripts that may pause the executor.
- **Student decisions:** never accept them on the student's behalf ("Accept as is", polarity, pin verification).
- **Ordering:** no orders or uploads to JLC.
- **`runtime/AGENTS.md`:** it must stay at 150 lines or fewer, which a test enforces. Edit an existing line rather than adding one.
- **Scope:** work only on what advances the generic system. No fixes or questions that apply to one board only.
- **Reports to the user:** short Hebrew, every line starting with a Hebrew word.
