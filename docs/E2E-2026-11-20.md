## כשלים
1. **חדש, חוסם: השרטוט מוסיף לפרויקט האלטיום רק את ה-SchDoc החדש הראשון.**
   - אחרי פיצול ל-4 גיליונות, Verify-Neon.PrjPcb הכיל רק את Main ואת 02, גם בדיסק וגם בזיכרון של אלטיום.
   - Place parts נכשל עם "The schematic is not drawn in Altium for C1, C15, …".
   - ציור מחדש עם Replace נכשל עם "Sheet 03 … is no longer in the Altium project".
   - **סיבה סבירה:** ‏`scripts/altium/bridge/AdvisorBridge.pas:173`. ‏NewDocument מוסיף לפרויקט במפורש רק מסמך PCB, ומסמך SCH נשאר תלוי בפרויקט שבפוקוס. אחרי הגיליון החדש הראשון הפוקוס כבר לא על הפרויקט. הפקודות נבנות ב-`bridge.py:895`.
   - **הסוכן:** agy אבחן את הבעיה נכון מהצ'אט ונתן צעדים ידניים: Add Existing to Project ואז Save All.
   - **עקיפה בבדיקה:** סקריפט sandbox עם DM_AddSourceDocument ושמירת ה-PrjPcb, כמו שסטודנט היה עושה ידנית.
   - **השפעה:** כל לוח שמתפצל ל-3 גיליונות או יותר.
2. **דוח פעילות: נתיב הבית של המשתמש דולף בקבצים הגולמיים.** ב-timeline.txt הנתיבים מוסתרים, אבל בשאר הקבצים לא:
   - `logs/run-project.jsonl` נכתב בלי `home_paths`, וכולל למשל את נתיבי ה-DRC ב-Temp (`scripts/runlog.py:645`).
   - `doctor.json` עובר `redact` בלי `home_paths`, וכולל את הנתיב של agy.EXE (`scripts/runlog.py:709`).
   - ב-`project/turns-log.jsonl` יש 16 מופעים. נתיב שנמצא בתוך JSON שמוטמע ב-JSON כתוב עם 4 לוכסנים, והביטוי `_PROFILE_RE` (`scripts/runlog.py:378`) מכסה רק 1 או 2.
3. **ספרייה לפני שיש פרויקט אלטיום:** ההודעה "No Altium project is linked to this project yet. Create one first." מופיעה בלי כפתור ליצירת הפרויקט.
4. **השמה על 40x30:** הלוח שנגזר מהרעיון קטן מדי ל-43 רכיבים בצד אחד. ההודעה נכונה, אבל צריך לחזור לדף Idea כדי להגדיל אותו.
5. **ניתוב:** ‎+1V1, ‏+3V3 ו-USB_DM לא נותבו. זו מגבלה מוכרת ומאושרת (fixture של xfail עד שיהיה fan-out). ‏USB_DM נוסף הפעם לרשימה.
6. **רעש בסיכום ה-DRC בצ'אט:** שמות חוקים חוזרים פעמיים, למשל "Minimum Annular Ring 0, Minimum Annular Ring 7" ו-"Silk To Solder Mask 0 … 29". ההודעה מתחת לתצוגה נקייה.
