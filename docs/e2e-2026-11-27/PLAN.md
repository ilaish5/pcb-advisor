# הרצת ניסיון סופית מקצה לקצה – לוח חדש (לילה 27–28/11/2026)

## מטרה
סטודנט מדומה בונה לוח חדש מאפס דרך ממשק הדפדפן בלבד, מרעיון ועד בדיקת DFM ב-JLC.
צוות בודקים ביקורתי מלווה אותו. נבדקת **המערכת**, לא הלוח ([system-over-boards]).
התוצרים: דוח ממצאים ממוין לפי חומרה, צילומי מסך לכל שלב, ופסק דין לכל תפקיד.

## הלוח (נבחר: 4 שכבות, מורכב)
**STM32F411 USB-C sensor hub**: STM32F411CEU6 (QFN48), קריסטל 25MHz וקריסטל 32.768kHz, LDO 3.3V, USB-C 2.0 עם ESD,
פלאש SPI W25Q128, IMU ב-SPI, חיישן BME280 ב-I2C, microSD, מחבר SWD, 2 נוריות, לחצני RESET ו-BOOT0.
4 שכבות (Top / GND / PWR / Bottom), כ-70 רכיבים. הפרויקט ייקרא `Final-E2E-4L`.

החלטות שהתקבלו לפני הריצה:
- אלטי בודק דרך סקריפטי המערכת ו-PDF שמיוצא מ-Altium.
- באג חוסם מתוקן (Sonnet, סקירת Opus, push) והריצה ממשיכה.
- ב-JLC: העלאה ובדיקה בלבד.

## השלבים והשער בסוף כל אחד
לכל שלב: הסטודנט עובד ← צילומים נשמרים ב-`screens/NN-stage-step.png` ← שלושה בודקים במקביל (המרצה, המעצב, המהנדס; ואלטי בשלבים 3–7) ←
המרצה מעמת את הסטודנט ← הסטודנט מתקן דרך הממשק ← המרצה מאשר ← השלב הבא.

1. **רעיון**: פרויקט חדש, תיאור חופשי בצ'אט ואישור דרישות.
2. **BOM**: בחירת רכיבים, מלאי ו-LCSC, דפי נתונים ופינאאוטים.
3. **ספרייה**: Build library ב-Altium, כולל סימבולים, footprints ובדיקת פדים.
4. **סכמה**: תצוגה מקדימה, "ציירי לי" ב-Altium, ERC ופינים פתוחים (NC).
5. **PCB**: מתאר, מיקום רכיבים, decaps ליד ה-MCU וקריסטל צמוד.
6. **ניתוב**: Route, USB כזוג דיפרנציאלי, DRC נקי.
7. **תוצרים**: Gerbers, BOM ו-CPL דרך outjob, ובדיקת "לפני הזמנה".
8. **DFM**: היצרן מעלה את ה-zip ל-JLC, קורא את הדוח וממפה כל אזהרה למקור שלה במערכת.

## כללי עבודה
- רק המתזמר מתקשר בין התפקידים. הם כותבים ל-`roles/<role>.md` ומדווחים אליי.
- Chrome משותף: רק הסטודנט משתמש בו, והיצרן נכנס רק אחריו. אני לא נוגע בו בזמן הריצה.
- זיכרון: מחשב עם 8GB, ופנויים כ-2GB כש-Altium ו-Chrome פתוחים. לכן לכל היותר 3 סשנים עובדים בו-זמנית, והבודקים רצים לפי שלב ונסגרים.
- **באג חוסם** במערכת: מתועד, ואז נבחר מעקף, או תיקון בסשן Sonnet עם סקירת Opus ו-push (לפי תשובה 2 למטה).
- אסור: הזמנה או תשלום ב-JLC, מחיקת פרויקטים אחרים, שינוי הגדרות אבטחה.
- התאוששות: בדיקה עצמית בכל שעה (cron), כדי שהעבודה תמשיך אחרי איפוס מגבלת השימוש.
- מחלוקת (למשל המרצה מול הסטודנט, או המהנדס מול אלטי): אני מכריע לפי עדות ראשונית (קובץ, דף נתונים, דוח DRC) ומתעד ב-`DECISIONS.md`.
